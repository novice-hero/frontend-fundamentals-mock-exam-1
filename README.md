## 회고
과제 전형 같은 플로우가 처음이다 보니, 제한 시간 2시간 이내에 구현하는 것에 요구사항 분석 시간이 포함인지 아닌지 부터 헷갈렸다. 일단 요구사항 분석시간도 포함해서 진행하려고 했고, 모의고사니까 개인적으로 공부하는 느낌으로 하자해서 ai도 최대한 자제하려고 했다.

그러다보니 시간적 압박이 꽤 느껴졌고, 요구사항 분석을 제대로 하지 못하고 구현을 들어갔다. 그래서 미처 생각하지 못했던 부분들이 있어 꼬이는 부분도 있었고, 처음 생각했던 것들을 적용하지 못한것도 있었다. 또한 마음가짐도 너무 편한게 가졌는지, 집중력도 떨어져서 꽤나 아쉬운 모의고사 였다.
